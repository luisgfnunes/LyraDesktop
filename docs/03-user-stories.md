# User Stories (Histórias de Usuário)

* **US01:** Como usuário, quero digitar o nome de uma música na barra de busca para encontrar faixas para ouvir.
* **US02:** Como usuário, quero clicar em um resultado da busca para que a música comece a tocar imediatamente.
* **US03:** Como usuário, quero ver a arte do álbum, título e artista no "Now Playing" inferior para saber o que está tocando.
* **US04:** Como estudante (Desenvolvedor), quero que a comunicação com a API use engenharia reversa para entender como clientes oficiais de grandes empresas estruturam seus payloads.
