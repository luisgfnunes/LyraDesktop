# LyraDesktop
Cliente desktop de streaming de música utilizando C++

# Projeto de Estudo: C++ Music Player (Estilo YT Music)

Este é um projeto pessoal com foco no aprofundamento prático em Engenharia de Software. O objetivo é construir um cliente desktop de streaming de música utilizando C++, aplicando boas práticas de arquitetura, documentação e engenharia reversa de APIs.

**Stack Tecnológico Principal:**
* Linguagem: C++ (Moderno)
* GUI: Qt / QML
* Dados: InnerTube API (Engenharia Reversa)
